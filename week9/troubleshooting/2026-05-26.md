# [에이전트] [2026-05-26] 트러블슈팅 리포트

## 1. KoNLPy Mecab 클래스 호출 시 NameError 발생
- **현상**: `NameError: name 'Tagger' is not defined` 및 `Exception: Install MeCab in order to use it: http://konlpy.org/en/latest/install/` 에러 발생.
- **원인**: KoNLPy의 `Mecab` 클래스는 파이썬 자체 구현이 아니라 C/C++로 작성된 오픈소스 형태소 분석기 `MeCab`을 호출하는 래퍼(Wrapper)입니다. 시스템(WSL Ubuntu)에 `mecab-ko` 엔진, `mecab-ko-dic` 사전, 그리고 파이썬용 MeCab 바인딩 라이브러리(`mecab-python3`)가 설치되지 않아 발생한 의존성 문제입니다.
- **해결**:
  다음 두 단계를 통해 필요한 라이브러리를 설치하여 해결할 수 있습니다.
  
  **방법 A: MeCab 직접 설치 및 연동**
  1. WSL 터미널 환경에서 KoNLPy 공식 제공 MeCab 자동 설치 스크립트 실행:
     ```bash
     bash <(curl -s https://raw.githubusercontent.com/konlpy/konlpy/master/scripts/mecab.sh)
     ```
     *(중간에 `sudo` 권한 비밀번호 입력을 요청할 수 있습니다.)*
  2. 현재 활성화된 가상환경(`.venv`) 내에 파이썬 바인딩 패키지 추가 설치:
     ```bash
     uv pip install mecab-python3
     ```
  
  **방법 B: 현대적인 Kiwi 분석기 (`kiwipiepy`) 대안 사용**
  - 복잡한 C++ 컴파일 및 외부 스크립트 실행 없이, 앞선 답변에서 추천드리고 이미 종속성에 세팅해 둔 `kiwipiepy`를 사용하여 동일하게 뛰어난 성능(C++ 기반 속도)과 사용자 사전 기능을 활용합니다.
- **교훈**: C/C++ 컴파일 엔진에 종속되는 분석기(Mecab 등)는 파이썬 설치만으로 작동하지 않으며 OS 수준의 추가 설정이 필요합니다. 개발 환경의 손쉬운 이식성과 협업을 중시하는 경우, 순수 파이썬 바인딩으로 패키지 매니저를 통해 손쉽게 설치 및 연동되는 `Kiwi` 같은 최신 솔루션을 적용하는 것이 시스템 안정성과 이식성 측면에서 우수합니다.
