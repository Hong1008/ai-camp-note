# Troubleshooting: 라이브러리 v5 마이그레이션 및 한국어 ROUGE 평가 디버깅 (2026-06-05)

오늘 자연어 처리(NLP) 실습 및 트랜스포머 활용 과정에서 발생한 라이브러리 버전 업그레이드 충돌과 한글 ROUGE 스코어 집계 오류에 대한 원인 분석 및 해결 과정을 기록합니다.

---

## 1. Pandera `SchemaModel` AttributeError
* **현상**: `AttributeError: module 'pandera' has no attribute 'SchemaModel'` 에러와 함께 데이터 검증 클래스 정의가 불가능함.
* **원인**: 
  * `pandera` 라이브러리가 메모리에 로드될 때, 가상환경 내의 `pydantic` 라이브러리와의 버전 불일치 또는 동적 임포트 차단으로 인해 레거시 구조인 `SchemaModel`이 네임스페이스에 바인딩되지 못함.
* **해결**:
  * Pandas 데이터프레임의 어절 단위 타입 검증에 최적화된 최신 표준 선언형 클래스인 **`pandera.DataFrameModel` (또는 `pa.DataFrameModel`)**을 상속받도록 모델 정의를 수정하여 패키지 구조에 무관하게 작동하도록 조치함.

---

## 2. Transformers `AdamW` ImportError 및 파라미터 에러
* **현상 1**: `ImportError: cannot import name 'AdamW' from 'transformers'` 에러 발생.
* **현상 2**: `AdamW` 임포트 우회 후 `TypeError: __init__() got an unexpected keyword argument 'correct_bias'` 에러 발생.
* **원인**:
  * 과거 버전에는 L2 Regularization 보정을 위해 Hugging Face가 자체 구현한 `AdamW`가 사용되었으나, PyTorch 1.2.0부터 성능이 개선된 자체 `torch.optim.AdamW`가 포함됨에 따라 중복을 방지하고자 `transformers` v5.x에서 해당 모듈이 완전 삭제됨.
  * 이에 따라 PyTorch 내장 `AdamW`에는 Hugging Face 전용의 가중치 편향 감쇄 차단 옵션인 `correct_bias` 인자가 존재하지 않아 에러를 유발함.
* **해결**:
  * 옵티마이저 임포트 소스를 **`from torch.optim import AdamW`**로 일원화하고, `optimizer = AdamW(model.parameters(), lr=2e-5)` 처럼 **`correct_bias` 파라미터를 완전히 제거**하여 연동함.

## 3. `BertTokenizer` has no attribute `encode_plus`
* **현상**: `AttributeError: BertTokenizer has no attribute encode_plus` 에러 발생.
* **원인**:
  * `transformers v5` 이상부터 기존의 명시적인 전처리 메서드(`encode_plus`, `batch_encode_plus`)들이 삭제되고, 토크나이저 객체를 함수처럼 바로 호출하는 단일 인터페이스(`__call__`)로 통합됨.
* **해결**:
  * `tokenizer.encode_plus(...)` 대신 **`tokenizer(...)`** 객체 함수 호출로 리팩토링함.

---

## 4. 한국어 ROUGE 평가지표 `0.0000` 고정 에러
* **현상**: 한글 요약본에 대해 형태소 분리(`Kiwi`)를 적용했음에도 ROUGE F1-Score가 모든 모델에서 `0.0000`으로 측정됨.
* **원인**:
  * 구글의 `rouge-score` 및 Hugging Face `evaluate` 내부 토크나이저 엔진인 `NLTK`는 비-아스키(Non-ASCII) 문자인 한글 유니코드를 단어로 취급하지 않고 문장부호처럼 무시하여 `[^a-z0-9]` 정규식에 의해 빈 텍스트로 치환함.
* **해결 (유니코드 영문 맵핑 우회)**:
  * 형태소 단위로 분리된 한글 어절을 고유한 영어 ID 문자열(예: `"디아블로"` $\rightarrow$ `"w0"`, `"게임"` $\rightarrow$ `"w1"`)로 일대일 변환하여 계산기에 주입하는 **영문 맵핑 전처리 함수**를 자체 제작하여 무사히 정량적인 ROUGE 스코어를 산출함.
