## 🗓️ 학습 로드맵 및 수행 결과

### 🟢 Theme 24: 자연어 처리(NLP) 기초 및 한국어 전처리 (2026-05-26)
텍스트 원시 데이터를 기계학습 모델에 입력 가능한 형태로 변환하기 위한 전처리 파이프라인을 구축했습니다.
- **핵심 성과**:
    - **정규식 기반 텍스트 정제**: 특수문자, 이모지, 불필요한 공백을 정규표현식으로 정제
    - **한국어 토큰화**: `Okt`, `Kkma`, `Mecab`, `Kiwi` 분석기 성능 비교 및 외부 컴파일에 종속되지 않고 한국어 뉘앙스를 가장 정밀하게 분석하는 `Kiwi` 분석기로 정착
    - **품사 Whitelist 필터링**: 불용어 사전(Blacklist)에 의존하는 한계를 극복하기 위해 핵심 의미 품사(`NNG`(일반명사), `NNP`(고유명사), `VV`(동사), `VA`(형용사), `XR`(어근))만 추출하는 화이트리스트 토큰화 로직 구현
    - **불용어(Stopwords) 정제**: 분석 도메인에 무의미하게 자주 등장하는 단어 정제

### 🟢 Theme 25: 텍스트 Vectorization & 유사도 분석 (2026-05-26)
텍스트 데이터를 수치적 벡터로 변환하는 표현 기법과 거리/방향 유사도 계산을 적용했습니다.
- **핵심 성과**:
    - **전체 말뭉치 대표 TF-IDF 추출**: 전체 데이터셋에서 각 단어의 TF-IDF 평균 점수를 구하고, `'배달'`, `'주문'`, `'앱'` 등 도메인 고유의 중복 단어들을 도메인 특화 불용어로 2차 제거함으로써 실질적 비즈니스 이슈(`'메뉴'`, `'전화'`, `'불편'`, `'취소'`, `'결제'`) 상위 키워드 정렬 완료
    - **코사인 유사도(Cosine Similarity) 기반 VOC 매칭**: 1차원 벡터로 변환된 리뷰 데이터 간 유사도 각도를 연산하여, 특정 타겟 리뷰(예: 시스템/인증 불편)와 문맥상 가장 가까운 유사 리뷰 Top 3를 자동으로 검색해내는 검색 엔진 파이프라인 검증 완료

### 🟢 Theme 26: 잠재 디리클레 할당(LDA) 기반 토픽 모델링 (2026-05-26)
단어의 동시 출현 빈도를 기반으로 데이터셋에 내재된 잠재 피인 포인트(Pain Points)를 분류하고 시각화 분석을 진행했습니다.
- **핵심 성과**:
    - **CountVectorizer + LDA 연산**: 전체 리뷰 데이터셋을 상호 배타적인 5가지 비즈니스 토픽(프로모션, 고객센터, UI/UX, 소량주문 조건, 업데이트 에러)으로 라벨링 완료
    - **pyLDAvis 대시보드 시각화**: 차원 축소 기법(t-SNE/MDS)을 활용해 2차원 공간 상에 토픽 간 거리를 맵핑하여 5가지 토픽이 겹치지 않고 잘 분리되었음을 시각적으로 확인
    - **람다($\lambda$) 튜닝**: $\lambda \approx 0.6$ 설정을 통해 범용 단어와 각 토픽의 독점적 단어 간 최적의 균형점을 도출하여 정밀 라벨링 프로세스 확보

### 🟢 Theme 27: 텍스트 네트워크 분석 (Semantic Network Analysis) (2026-06-01)
텍스트 내 단어들 간의 동시 출현(Co-occurrence) 관계를 규명하고, 이를 시각적 네트워크로 구상했습니다.
- **핵심 성과**:
    - **동시 출현 빈도 기반 가중 그래프 생성**: 리뷰 내에서 함께 출현한 단어 쌍을 집계하고 `NetworkX`를 사용해 가중치 엣지를 갖는 그래프로 시각화
    - **중심성 지표 분석**: 연결 중심성(Degree Centrality), 매개 중심성(Betweenness Centrality), 근접 중심성(Closeness Centrality)을 도출하여 텍스트 내 중추적인 역할을 담당하는 핵심 의미 명사 매핑 완료

### 🟢 Theme 28: 머신러닝 기반 한국어 감성 분석 (Sentiment Analysis) (2026-06-01)
NSMC 데이터셋과 배달의민족 리뷰를 활용해 긍/부정 감성 분류 모델을 구축하고 비즈니스 분석 파이프라인으로 연결했습니다.
- **핵심 성과**:
    - **Pandera 스키마 검증**: 데이터 입력 단계에서 결측치 및 타입, 라벨의 유효 범위([0, 1])를 사전 검증하여 실무용 파이프라인의 견고함 확보
    - **감성 분류 예측 모델 비교**: Kiwi 형태소 토큰화 + TF-IDF 특징 추출 후, Logistic Regression(정확도 우수, 과적합 제어)과 LightGBM 모델의 성능 및 혼동 행렬을 다각도 분석
    - **비즈니스 부정 피드백 탐지 연계**: 학습 모델을 배달의민족 리뷰에 적용해 Sentiment Score(긍정 확률)를 산출하고, 0.3 이하의 부정적 리뷰 데이터셋만을 필터링하여 사용자 불만 키워드에 대한 2차 Semantic Network를 시각화함으로써 비즈니스 취약 부문(예: '고객센터', '전화', '연결', '지연') 즉각 탐지 체계 구축

### 🟢 [미니프로젝트]: 서울자전거 따릉이 VOC 분석 리포트 (2026-06-01)
Play Store 대용량 데이터(9.6k)와 App Store RSS API를 직접 활용해 한국어 텍스트 분석 파이프라인(빈도, 네트워크, 토픽, 감성 모델)을 종합한 실무 리포트를 작성했습니다.
- **핵심 성과**:
    - **공식 API 기반 크롤링 우회**: app-store-scraper의 인코딩/토큰 변경 버그를 우회하기 위해 **iTunes RSS Feed JSON API**를 활용한 500건 다이렉트 수집 코드 확보
    - **Kiwi 형태소 사전 튜닝**: `'개발자모드'`, `'대여소'`, `'정기권'` 등을 사용자 정의 단어 사전에 등록하여 형태소 경계 오작동 최소화
    - **LDA 토픽별 문서 점유 비중 검증**: 4개 토픽의 정량적 점유율(시스템 에러 36.6%, 긍정적 이용 28.0%, 대여 장애 27.2%, 지도 불편 8.1%)을 산출하여 모델 최적화(K=4) 정당성 확보
    - **NetworkX 단어 네트워크 임계치 튜닝**: THRESHOLD=150 상향 설정을 통해 완전 그래프 쏠림 현상을 해소하고, `'이용'`과 `'대여'`를 핵심 허브 노드로 삼는 의미 네트워크 컴포넌트 규명
    - **감성 모델 피처 가중치 검증**: TF-IDF + Logistic Regression 모델(정확도 **85.34%**)을 학습하고, 회귀 가중치를 분석하여 `'세금'`, `'공무원'`, `'걸어가'`, `'날리'` 등 공적 불만 및 사용자 피해 키워드 포착
    - **우선순위 기반 개선 전략 제안**: 토픽 점유율 비중을 기준으로 리소스 투입 우선순위(서버 안정화 -> 블루투스 페어링 -> 롱테일 보안 및 지도 UI 튜닝)를 설계한 개선 기획 제안서 수립

## 📊 한국어 형태소 분석기 비교 분석

한국어는 교착어 특성상 어근에 조사가 붙어 단어를 형성하므로 단순 공백 기준 토큰화가 불가능하며, 형태소 분석기의 선택이 성능과 속도에 직결됩니다.

| 분석기 명칭 | 라이브러리 | 엔진 기반 | 처리 속도 | 정확도/특성 | 추천 활용 분야 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Okt** | KoNLPy | Java | 보통 | 오탈자가 포함된 정제되지 않은 SNS 데이터 분석에 강점 | 소셜 미디어 분석, 감성 분석 |
| **Kkma** | KoNLPy | Java | 매우 느림 | 문장 분석이 정교하며 품사 태그가 세분화되어 있음 | 고정밀 문법 분석 |
| **Mecab** | KoNLPy | C++ | **압도적으로 빠름** | 대용량 텍스트 분석에 필수적이며 분석 품질이 우수함 (외부 의존성 존재) | 뉴스 기사, 대규모 코퍼스 분석 |
| **Kiwi** | kiwipiepy | C++ | **매우 빠름** | 사용자 사전 추가가 직관적이고 띄어쓰기 교정 기능이 뛰어남 (순수 파이썬 패키징 지원) | 최근 실무 프로젝트, 검색 매칭 |

## 📈 LDA 토픽 모델링 분석 결과 및 우선순위

모델링을 통해 도출된 5가지 잠재 토픽의 세부 내용과 비즈니스 영향도 매트릭스입니다.

| 토픽 번호 | 핵심 단어 구성 | 정의 및 사용자 불만 맥락 | 비즈니스 영향 및 우선순위 |
| :--- | :--- | :--- | :--- |
| **Topic #1** | 쿠폰, 이용, 문제, 만들, 알뜰, 할인, 광고 | 신규 배달 프로모션(알뜰배달 등) 이용 시 쿠폰 미적용 및 과도한 광고 노출 피로도 | 4순위 (Low) - 마케팅 노출 제한 및 광고 피로도 조율 필요 |
| **Topic #2** | 전화, 취소, 고객, 센터, 연결, 상담, 기다리 | 주문 취소 요구 시 고객센터(상담, 채팅) 연결이 지연되어 발생하는 대기 시간 지연 불만 | 2순위 (High) - 조건부 즉시 자동 취소 프로세스 도입 권장 |
| **Topic #3** | 검색, 주소, 카테고리, 입력, 내역, 불편, 스크롤 | 주소 설정 오류, 카테고리 필터 검색 및 주문 내역 스크롤 등 앱 사용 인터페이스 오작동 | 3순위 (Medium) - 검색 경로 및 터치 감도 UI/UX 튜닝 프로젝트 연계 |
| **Topic #4** | 이하, 알림, 음식점, 정렬, 최소, 인분, 노출 | 1인분 소량 주문 시 매장별 최소주문금액 설정 문제 및 이에 따른 필터링 노출 정렬 제한 | 3순위 (Medium) - 1인 가구 타겟 정렬 알고리즘 및 필터 개선 |
| **Topic #5** | 메뉴, 리뷰, 기능, 결제, 불편, 업데이트, 식당 | 앱 업데이트 진행 직후 결제 불가, 메뉴판 미노출, 리뷰 작성 먹통 등 주요 트랜잭션 오작동 | **1순위 (Critical)** - 핫픽스 대응 및 릴리즈 전 디바이스 호환성 QA 강화 |
